# 稀疏矩陣測試設計

從作業資料夾執行：

```powershell
python -m unittest discover -s tests -v
```

測試獨立於正式模組，不會改變互動輸入流程。`test_results.txt` 保存本次實際執行結果。

| 編號 | 測試重點 | 預期結果 |
|---|---|---|
| 01 | PDF 的 4×5 範例、空列、兩種輸出 | 數值與輸出字串完全符合預期；記憶體 29 單位 |
| 02 | 亂序、重複欄號、刪除尾端後再插入、輸入零值 | 最後一筆覆寫前值；結果為 `0 -1 0 7 0`，節點仍排序 |
| 03 | 插入首中尾、更新、刪除首中尾、讀取未存位置 | 更新成功；未存位置為 0；全部刪除後列入口為 None |
| 04 | 加法合併、相同欄相加、零值抵銷 | 結果為 `2 8 8 0 0` 與全零列；不儲存零節點 |
| 05 | 正負值取負、減法、自減 | 負矩陣正確；A−A 不含元素節點 |
| 06 | 長方形轉置、轉置兩次、單列全零矩陣 | 交換尺寸；轉置兩次還原原值 |
| 07 | 3×3 乘 3×2、零列、1×2 乘 2×1、1×1 零矩陣 | 結果為 `4 21`、`0 24`、`0 0`；內積抵銷不建節點 |
| 08 | 加減法尺寸不一致、乘法內側尺寸不一致 | 各運算拋出 ValueError |
| 09 | 修改各運算的結果節點 | A、B 的數值保持不變，沒有共用結果節點 |
| 10 | 固定種子的 100 組小型亂數資料 | 乘法對照三層數學公式；另驗證轉置、加法、自減 |
| 11 | 主程式的加減法與乘法維度判斷互不影響 | 無法相加仍可相乘；無法相乘仍可相加；輸出含記憶體 |

每次 `check_matrix()` 都直接檢查鏈結串列，確認列數、欄號排序、非零數值、尾端結束及記憶體公式，而非只檢查印出的畫面。

測試使用小型 Python 二維串列作為獨立預期答案；正式矩陣儲存和運算沒有使用二維陣列。這些是正確性測試，不能作為時間複雜度或大規模效能的實驗證據。非法輸入格式與越界索引不在本次測試範圍，正式程式目前假設輸入合法。

## 報告可使用的主程式執行範例

在作業資料夾執行：

```powershell
Get-Content sample_add_input.txt | python main.py
Get-Content sample_multiply_input.txt | python main.py
```

第一組示範加減法與乘法尺寸錯誤；第二組示範長方形乘法與加減法尺寸錯誤。完整實際輸出分別存放於 `sample_add_output.txt`、`sample_multiply_output.txt`。
